# Perinfoan Hub

Platform dan ekosistem proyek kolaboratif untuk wadah belajar, berdiskusi, dan bereksperimen bagi anggota grup Perinfoan.

## Language

### Identitas & Komunitas

**Member**:
Individu yang tergabung dalam grup Perinfoan (closed circle), memiliki profil yang mencakup identitas, peran santai/teknis, serta kontribusi proyek.
_Avoid_: User, Account, Contributor, Pengguna, Anggota Baru

**Web Profile**:
Aplikasi web utama yang menyajikan identitas grup Perinfoan, daftar Member, dan etalase seluruh Project.
_Avoid_: Landing Page, Homepage, Portal

### Proyek & Kontribusi

**Project**:
Aplikasi web, eksperimen, game, atau kakas independen yang dikembangkan oleh Member dan dapat diakses secara mandiri.
_Avoid_: Sub-app, Modul, Feature, Repository

**Showcase**:
Representasi kartu ringkasan sebuah Project di dalam Web Profile yang memuat nama, deskripsi singkat, tech stack, nama Member pembuat, dan tautan langsung ke Project tersebut.
_Avoid_: Katalog, Feed, List
